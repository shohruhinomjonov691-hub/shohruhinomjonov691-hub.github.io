IncidentPulse

When a health check fails, specialist agents gather infrastructure, log and code evidence through read-only MCP tools. If diagnoses disagree, a debate step compares them. The system then proposes one allowlisted fix — and nothing runs until a human approves it in Telegram or the dashboard. After that it checks recovery and writes a postmortem.
